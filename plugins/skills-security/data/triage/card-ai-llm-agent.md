1. A token written in an agent config, or an API base URL pointing to an unknown host: alert.
2. A hook, helper, folder-open task or dev-container host command that runs a script from the repository: investigate; it is persistence when the script fetches or decodes code.
3. Hidden characters, escape codes or invisible text in instructions: alert; nobody hides normal instructions.
4. Permission checks turned off in a file the person keeps for themselves (settings.local.json, not committed): hardening.
5. An unpinned package runner for an MCP server: hardening.
6. A remote MCP server over https to a known vendor: dismiss.
