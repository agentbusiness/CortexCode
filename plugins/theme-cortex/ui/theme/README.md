# @cortex-ui/theme-cortex-theme

CortexCode's design language, as the workbench's one theme plugin.

- **Plugin id:** `theme-cortex.theme`
- **Slot:** `theme@1` (exactly one theme is active; a newer build of it replaces it live)
- **Build:** `npm run build` → `dist/` (`index.js`, `style.css`, `fonts/`, `manifest.json`)
- **Test:** `npm test`

## What it provides

- **Tokens** in `tokens/cortex.tokens.json` (W3C Design Tokens format). Each color has its plate
  (dark ground, the default) value as `$value` and its page (light ground) value under
  `$extensions["org.cortexcode.ground"].page`; `font.reading`, `font.apparatus` and `font.mono` name
  the faces. `build-theme.mjs` compiles them to CSS custom properties on `#cc` for both grounds
  (`data-view="plate" | "page" | "auto"`), the design's names (`--ground`, `--ink`,
  `--rubric`, `--counter`, `--rule`, …) plus `--font-reading`, `--font-apparatus`, `--font-mono`.
- **Faces**, bundled: Source Serif 4 (reading) and Archivo (apparatus) as WOFF2 files in
  `dist/fonts/`, loaded from the frame (no network).
- **Base and component styles**: the design's reference rules and component sheet (verbatim but
  for the token block, which comes from the DTCG file), and `src/primitives.css`, the shared
  primitives other plugins compose (`.cx-pip`, `.cx-plus`/`.cx-minus`, `.cx-panel`, `.cx-sec`,
  diff rows, merge-view detents, toasts, slot states).
- **Derived themes**, published through `@cortex/sdk` (`publishTheme` → `activeTheme()`,
  `subscribeTheme`, `useThemeData`): the CodeMirror theme and highlight style, and xterm palettes
  for both grounds. The editor and the terminal restyle when the theme changes.

## Making another theme

Copy this package, change the tokens (and, if wanted, the faces and rules), give it another id in
`package.json` (`cortex.id`) and build it. Whichever `theme@1` plugin the frame serves with the
highest version is the active one. Other plugins never name a color, a font family or an
off-lattice size; they use the tokens and primitives, so they follow any theme.
