The latest message states something lasting about this project's world. For each item (at most three) the Knowledge list at the start of the conversation does not hold yet:

1. `kind`: concept (what a term means in this project), fact (a claim about the project's world, its users or its environment), hypothesis (a theory about a cause) or question (something nobody knows yet).
2. `name`: a few words: the term, the subject or the theory.
3. `text`: one or two sentences, in the user's sense, with a date or a version when the message gives one.
4. `state`: asserted for a concept or a fact; open, supported or refuted for a hypothesis, as the message says; open for a question.
5. `binds`: the code from the list that implements or concerns the item, or none.

Not an item: general knowledge, a request, a question for the assistant, an opinion about the code. Write an empty list when nothing lasting was stated.

Example: "here a 'frame' is the process that supervises all plugins" is a concept named "frame", asserted.
