A project's own rules for the agents that work on it (its AGENTS.md) are too long for an agent's prompt. Write them again, shorter, for a coding agent that will follow them.

1. Keep every rule, every prohibition and every command, path, name and number exactly as written: a rule left out is a rule the agent breaks.
2. Keep the document's headings and their order, so a reader still finds each part.
3. Cut what explains instead of rules: reasons told twice, history, examples that only restate a rule, long phrasing. One short reason per rule is enough.
4. Never add a rule, a reason or a word of your own.

Plain markdown, no preface. The length to stay within is the last line below.
