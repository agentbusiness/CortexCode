The user wrote while a task of the plan was running. Say what their words ask for.

1. `kind`: question when they only ask how the work goes (progress, what is done, how long it takes). change when they ask anything of the work itself: to do it another way, add or drop a part, fix or stop something, or that it must meet something.

Example: "how far is it?" is question. "how far is it? use the larger file too" is change.
