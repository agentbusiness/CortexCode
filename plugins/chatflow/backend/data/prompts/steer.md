The user wrote while the plan's work was going on: a task running here, or agents carrying the plan out. Say what their words ask for.

1. `kind`: question when they only ask and want nothing changed (how the work goes, what is done, how long it takes, how a thing works). change when they ask anything of the work itself: to do it another way, add or drop a part, fix or stop something, or that it must meet something.

Example: "how far is it?" is question. "how far is it? use the larger file too" is change. "yes, the export must handle empty files too" is change.
