# @cortex-ui/scheduler-pane

The Schedule tab: every routine of the project and the global ones, edited in place, with their runs.

- **Plugin id:** `scheduler.pane`
- **Slot:** `pane.schedule@1`
- **Build:** `npm run build` → `dist/` (`index.js`, `style.css`, `manifest.json`)

React, ReactDOM and `@cortex/sdk` are peer dependencies the workbench provides.
