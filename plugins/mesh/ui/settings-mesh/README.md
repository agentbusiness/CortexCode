# @cortex-ui/mesh-settings

Settings > Mesh: this computer in the cortex (name, id), Add a computer (a code and the full
invitation), Join with a code, the members with their grants and Remove, the peers with their
reachability and cards, Model from (this computer or a member), the relay switch.

- **Plugin id:** `mesh.settings`
- **Slot:** `settings.mesh@1`
- **Build:** `npm run build` → `dist/` (`index.js`, `style.css`, `manifest.json`)
