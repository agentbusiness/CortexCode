# @cortex-ui/tools-card-timeline

The step log in the card: what every step of every session (and the user by hand) changed since
the last commit, with Undo to here, Undo this step and Redo.

- **Plugin id:** `tools.card-timeline`
- **Slot:** `card.timeline@1`
- **Build:** `npm run build` → `dist/` (`index.js`, `style.css`, `manifest.json`)

React, ReactDOM and `@cortex/sdk` are peer dependencies the workbench provides.
